PRODUCT PURPOSE

The Atmosphere Engine prevents the app from feeling empty when there is little real user activity.

It should create a constantly changing discovery atmosphere using legitimate discovery/generated content while prioritizing real user-generated content whenever it exists.

The goal is for every user to have something interesting to discover even when the community is still small.

DO NOT create fake users that can interact with people.

DO NOT create fake followers, fake likes, fake comments, fake messages, fake transactions, fake live viewers, fake room participants, or fake engagement metrics.

DO NOT represent generated content as being posted by a real human.

Generated/discovery content should have an appropriate discovery/suggested context so users are not misled about its origin.

CORE ENGINE

Create an Atmosphere Engine service that dynamically determines what content should appear to each user.

The engine should consider:

* user location when permission is available
* user’s selected interests
* profession/interests from onboarding
* Hubs they follow or explore
* Pace activity/interests
* previously viewed content
* previously dismissed content
* content category
* time of day
* day of week
* season
* geographic relevance
* popularity of legitimate data
* freshness
* diversity
* repetition
* distance
* language
* user engagement history

The engine must generate a different content mix for different users.

Two users opening the app should NOT necessarily see the same discovery cards.

CONTENT PRIORITY

The ranking hierarchy should generally be:

1. Real user-generated content
2. Legitimate external/public discovery data already supported by the app
3. Generated discovery/atmosphere content

Real user activity should gradually replace discovery content as the community grows.

Example:

No real activity:

* 80-100% discovery/atmosphere
* 0-20% real content

Some real activity:

* approximately 50-70% real
* remainder discovery

Strong activity:

* approximately 80-95% real
* small amount of discovery

Mature area:

* overwhelmingly real content

Make these percentages configurable rather than hard-coded.

IMPORTANT: LIVE

Do NOT generate synthetic live rooms.

Do NOT generate fake live participants.

Do NOT generate fake viewers.

Do NOT generate fake comments inside live rooms.

LIVE must remain 100% real.

If there are no live rooms, show the existing empty-state experience and encourage the user to start a real room if the current product supports that.
