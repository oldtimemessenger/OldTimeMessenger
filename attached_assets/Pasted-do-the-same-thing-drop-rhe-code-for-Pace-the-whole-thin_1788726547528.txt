How it would work technically

A professional filter needs three layers:

Camera preview
      ↓
Face detection and landmarks
      ↓
GPU filter rendering
The face detector tracks things like:

Eyes
Eyebrows
Nose
Lips
Cheeks
Jawline
Face outline
The GPU then applies the effects in real time while the user moves.

For example:

Cheek landmarks → skin smoothing mask
Eye landmarks → eye enhancement
Lip landmarks → lip color
Face outline → face reshape
Head position → glasses or hat placement
The important limitation

A basic Expo camera alone is not enough for this level of feature.

For professional live filters, we would need either:

Option 1: Native effects engine

Use a native camera/effects SDK designed for:

Live face tracking
Beauty filters
Makeup
AR masks
Video effects
High frame rates
This is the fastest path to a polished result.

Option 2: Build the effects ourselves

Use a native camera pipeline with:

Face tracking
ARKit on iOS
ARCore/ML Kit on Android
GPU shaders
Skia or a similar rendering layer
This gives Old Time a completely custom look and avoids making the app feel like a generic camera clone, but it requires more device testing.
