Build a premium, production-quality camera filter system for Old Time Messenger.

IMPORTANT: Do NOT build childish Snapchat-style sticker filters as the main experience. Do NOT use cheap-looking cartoon overlays, emojis, oversized ears, basic color tints, or novelty effects.

The goal is to make Old Time’s camera competitive with the beauty/photo effects users expect from FaceApp, Facetune, Snapchat, and Instagram.

The filters must make users look genuinely better while still looking like themselves.

CORE CAMERA EXPERIENCE

Create a polished full-screen camera with:

* Front and rear camera
* Live preview
* Real-time filters
* Smooth 60 FPS where device hardware allows
* Face detection / face landmarks
* Multiple faces supported
* Filter intensity slider
* Original / Before comparison
* Photo capture
* Video capture
* Flip camera
* Flash controls
* Zoom
* Save/share/send directly into Old Time
* No childish UI
* No excessive animations
* Premium iOS-style interface

FILTER 1 — OLD TIME FLAWLESS

This is the flagship filter and must be the best filter in the entire system.

The goal is:

“Make me look like the best version of myself.”

It should intelligently detect the face and apply subtle real-time enhancements:

* Natural skin smoothing
* Reduce temporary blemishes
* Reduce redness
* Reduce visible dark spots
* Soften under-eye darkness
* Improve skin tone consistency
* Subtle facial lighting
* Natural eye enhancement
* Slight lip color enhancement
* Subtle teeth whitening when teeth are visible
* Very subtle facial contour enhancement
* Improve overall facial symmetry without making the person look fake
* Preserve facial identity
* Preserve skin texture
* Preserve pores
* Preserve hair
* Preserve facial hair
* Preserve wrinkles naturally instead of completely removing them

CRITICAL:

The person must still look like themselves.

Do NOT create a plastic AI face.

Do NOT over-smooth skin.

Do NOT enlarge eyes unnaturally.

Do NOT make every person have the same face.

Do NOT dramatically change nose, jaw, lips, or facial structure.

The result should feel like excellent professional lighting + professional beauty retouching.

Include an intensity slider from 0–100%.

Default intensity should be around 35–45%.

IMPORTANT TECHNICAL REQUIREMENT

Do not fake the filters by simply placing PNG images over the camera.

Use actual face tracking / facial landmarks / segmentation where appropriate.

The system must distinguish:

* face
* eyes
* eyebrows
* nose
* mouth
* skin region
* hair
* background

Beauty filters must affect the appropriate facial regions rather than applying a generic blur to the entire camera image.

AR filters must track the face smoothly as the user moves.

PERFORMANCE

The camera must feel premium.

Avoid:

* noticeable lag
* filter jumping
* face tracking instability
* delayed overlays
* low-resolution preview
* excessive battery usage
* filters disappearing when the user moves

Optimize for modern iPhones first.

ARCHITECTURE

Create a reusable filter engine/API such as:

FaceTracker
BeautyFilter
